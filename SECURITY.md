# Reporting a security issue

For a published GitHub copy of this kit, use **Security → Report a vulnerability** when the repository owner has enabled private reporting. If a private reporting route is unavailable, ask the maintainer for one using a public issue containing only a contact request. Share the affected version, impact and a minimal example in private. Use synthetic data and redact credentials and personal details.

Before publishing a copy, enable private vulnerability reporting or replace this paragraph with a monitored private contact. Verify that a person outside the project can find the route. The owner of each generated project maintains its own reporting policy.
